# 🧩 Maze Solver Project

## 📘 Overview
The **Maze Solver** project is an interactive application that demonstrates how different graph traversal algorithms — **BFS (Breadth-First Search)**, **DFS (Depth-First Search)**, and **Dijkstra’s Algorithm** — work to find a path between a start and end point in a maze.

This project helps visualize the working, efficiency, and execution time of each algorithm, providing a clear comparison of their strengths and limitations.

---

## 🎯 Objectives
- To implement and compare BFS, DFS, and Dijkstra algorithms for maze solving.  
- To analyze each algorithm’s **execution time**, **visited cells**, and **path efficiency**.  
- To understand how different algorithms perform under varying maze conditions.

---

## ⚙️ Features
✅ Visual representation of maze solving  
✅ Comparison of algorithms based on:
- Execution Time  
- Number of Visited Cells  
- Path Cost (for Dijkstra)  

✅ Step-by-step visualization of traversal  
✅ Easy-to-understand code structure

---

## 🧾 Execution Time & Visited Cells (Example)

| Algorithm | Execution Time | Visited Cells |
|------------|----------------|----------------|
| BFS | Fast for unweighted graphs | Moderate |
| DFS | Slower for deep mazes | Fewer but may repeat |
| Dijkstra | Slower due to cost calculation | Highest |
